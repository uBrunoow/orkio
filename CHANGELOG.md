# Changelog

Todas as mudanças relevantes do Orkio ficam aqui, no formato
[Keep a Changelog](https://keepachangelog.com/pt-BR/1.1.0/), com versões [SemVer](https://semver.org/lang/pt-BR/).
A seção de cada versão vira as notas do release e o "O que há de novo" do app.
